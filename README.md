SRM AP Student Portal UI

A frontend recreation of the SRM University-AP student portal login page, created using HTML and CSS as a web development practice project.

Features

- Student portal login interface
- Freshers and senior student information sections
- Username and password input fields
- CAPTCHA-style UI
- Forgot password section
- Responsive layout for smaller screens
- Background image and university logo
- Clean two-column desktop layout

Technologies Used

- HTML5
- CSS3

What I Practiced

This project helped me practice:

- Forms and input fields
- Positioning
- Background images
- Responsive design using media queries
- Basic UI recreation

Note

This is a student-made frontend recreation created for learning and practice purposes. It is not an official SRM University-AP website or portal, and the login functionality is not connected to any real student account or university system.
